# Data

## Source
Public repository metadata from the **GitHub REST API** (`search/repositories`), collected with
[PyGithub](https://github.com/PyGithub/PyGithub) (`src/ingest.py`). Only technical metadata of public
repositories was collected (name, description, language, stars, forks, topics, dates). No personal data.

## Official snapshot
| | |
|---|---|
| File | `processed/repos_clean.csv` |
| Extracted | 2026-04-30 (~05:10 UTC), inferred from the derived day-count columns |
| Repositories | 3,034 (public, at least 50 stars, AI research topics) |
| Columns | 15 |

Every metric in the project is computed on this snapshot. Stars and activity change daily, so a new
extraction will give different numbers.

## Files
| File | What it is |
|---|---|
| `processed/repos_clean.csv` | Official snapshot, cleaned, with derived columns |
| `raw/repos_raw.csv` | 86-repository sample from the first iteration of the project (kept for reference; **not** the raw version of the 3,034-row snapshot) |
| `snapshots/<date>/` | Created by `python src/ingest.py` (ignored by Git) |
| `interim/*.npy` | Embeddings and feature matrices from notebook 02 (ignored by Git, regenerated by the notebook) |

## Columns of `repos_clean.csv`
| Column | Description |
|---|---|
| `repo_id`, `nombre`, `url` | GitHub id, `owner/name`, link |
| `descripcion` | Description (`No description` when empty: 3 repositories) |
| `lenguaje` | Main language (`Unknown` when GitHub reports none: 287 repositories) |
| `stars`, `forks` | Counts at extraction time |
| `topics` | List of GitHub topics |
| `fecha_creacion`, `ultimo_commit` | Creation date and last push (UTC) |
| `dias_sin_commit`, `antiguedad_dias` | Whole days from last push / creation to the extraction time |
| `num_topics` | Number of topics |
| `ratio_forks_stars` | `forks / stars`, 4 decimals |
| `stars_por_dia` | `stars / antiguedad_dias`, 4 decimals |

The cleaning and derived columns are implemented in `src/ingest.py::clean_and_engineer_features`;
`tests/test_ingest.py` checks that it reproduces this file.

## Regenerating
```bash
python src/ingest.py                 # new snapshot in data/snapshots/<date>/, official file untouched
python src/ingest.py --promote       # also replace data/processed/repos_clean.csv
python -m src.build_artifacts        # rebuild clusters and evaluation artifacts
```
The exact list of search queries used for the official snapshot was not preserved; `DEFAULT_QUERIES` in
`src/ingest.py` is a reconstruction over the same research topics, so a new run will not match the snapshot exactly.

## Known limitations
- 48 % of the repositories have had no push in over a year; they are kept because activity is a modelling signal.
- Stars are extremely skewed (median 2,174, maximum 194,936).
- Language `Unknown` groups several cases (documentation, notebooks, unclassified).
